# 初赛实施计划草案

目标是原底图上的固定 AUBO S3 + 腕部 D435i 自主抓放。当前阶段完成调查和工程基础；本计划中的实施、控制和比赛验证尚未完成。Q1–Q4 的回答决定物理模型、判分和最终交付边界。

## P0 · 资料、模型与接口边界

已核对三份 PDF、取到分工正文、检测 ROS/Gazebo 及控制插件 ABI、定位官方 S3 描述、建立按职责划分的目录。保留两张原图的页面比例、矢量路径、坐标及源文件哈希。

完成条件：用户确认交付边界、提供或接受明确标注的夹具/电池/安装假设，并澄清内圈可行性与两种任务的运行组织方式。无关这些问题的原始资料整理已经先行完成。

## P1 · 打通仿真依赖与 S3 关节控制

负责：张叔阳 + SJM。依赖：现有系统，无需等待评分口径。

1. 固定 Humble + Harmonic；在工程 overlay 编译与 Harmonic 匹配的 `gz_ros2_control`，固定 commit 和构建参数。
2. `ldd` 复核控制插件、bridge、Gazebo 主版本一致；完成 GUI、headless 和 WSL 图形渲染检查。
3. 为 S3 官方原 URDF 建组合 Xacro，保留真实连杆、惯量与关节限制，处理自带 world joint 和厂商扩展标签。
4. 配置 joint_state_broadcaster、joint_trajectory_controller，启动六关节运动和反馈。

验收：无缺失模型/插件，六关节轨迹 action 完成且反馈跟踪正常，固定基座不漂移，暂停/重置后状态明确。空场景通过不代替 S3 控制通过。

## P2 · 两张底图、道具、夹爪和腕部传感器

负责：张叔阳牵头；SJM 模型，韩明赫尺度，孙浩然图像。依赖：P1，Q2/Q3 的物理参数。

1. 分别生成 basic、sequence 两个 world，桌面贴原 PDF 导出的纹理，按实际 700×540 mm 比例和原图位置配置；不合并两图。
2. 电池模型使用确认的三维尺寸、质量、惯量、圆角、颜色和摩擦；未知参数在配置中标注来源及假设。
3. 安装已定夹具和 D435i，定义 TCP、相机安装外参及碰撞体，逐一检查 A/B/C/D、T0、P1/P2/P3 的可达性和路径间隙。
4. 复用官方 D435i 外形和内部 frame；添加 Gazebo RGB、depth/RGB-D、IMU 传感器，桥接图像、CameraInfo、IMU、时钟。真实 `realsense2_camera` 驱动用于实机模式，不用于凭空生成仿真图像。
5. 分辨率、视场、曝光/噪声、深度有效范围参数化；理想相机模型与拟真误差实验分开记录。

验收：原图关键区域位置与提取数据一致；腕部运动带动相机；RGB/深度/CameraInfo 时间和 frame 一致；深度值与已知桌面距离对照通过；夹具无明显穿模；所有目标位置有可用观察及操作姿态。

## P3 · 视觉、手眼与空间精度

负责：孙浩然 + 韩明赫。依赖：P2。

1. RGB-D 同步与对齐，桌面平面/高度分离，排除底图彩色印刷、文字和圆圈。
2. HSV 颜色 + 轮廓/旋转矩形 + 多点深度统计恢复电池位姿，估计朝向、置信度和抓取候选；不硬编码电池真实位置。
3. 维护腕部手眼变换、TCP、底图到基座关系；通过图像时间戳查 TF，加入过期观测和无效深度处理。
4. 在多个观察位和工作区点位量化颜色错误、XY/Z/yaw 误差、P95 与最大误差。

验收建议：固定测试集 1000 帧无颜色误报；先争取基座 XY 误差 P95 <3 mm，并公开误差分布。该数字来自团队工程目标，内圈尺寸未澄清前不能据此宣称满足内圈满分。

## P4 · 基础单块自主抓放闭环

负责：SJM 牵头任务调度、状态机和抓放执行；常建烁负责运动学、碰撞规划和轨迹生成。依赖：P1–P3、夹具参数。

运动规划的具体选型、输入输出、后处理边界与后续 B 样条优化路线见 [常建烁的运动规划实施方案](architecture/MOTION_PLANNING_PLAN.md)。

1. 常建烁建立 S3+夹具的 MoveIt SRDF、IK、规划与时间参数化配置，加入桌面、相机、非目标电池碰撞几何，并与 SJM 对齐控制器接口。
2. SJM 实现参数化口令、观察/选择/规划/执行/验证状态机和抓放动作；向规划模块提供目标 TCP 位姿、起始状态和运动约束。
3. 完成目标抓取、稳定离台至少 2 s、转运、T0 放置及释放后稳定至少 3 s。
4. 通过相机和夹爪反馈检查抓取与放置；超时、目标不可见、IK 失败和夹持失败进入有限重试或可解释终止。

验收：四种目标颜色分别运行，无人工中途介入；评分记录能逐项说明 40 分基础任务是否完成；抓错、掉落、碰倒事件可追溯。

## P5 · 三块序列与独立评分

负责：SJM 牵头序列任务和集成；常建烁负责各运动段规划，孙浩然验证，张叔阳评测。依赖：P4，Q2 内圈与姿态规则。

1. 支持运行时输入任意三种不同颜色的有序口令，依次放入 P1/P2/P3；不把“蓝红黄”写死。
2. 放置后复查颜色、位次、主体边界和稳定性，必要时进行有界恢复。
3. 独立评测器计算基础/序列各项、扣分和耗时，保留评测真值与控制链的接口隔离。
4. 原 80 mm 圆与电池形状若仍冲突，保留真实边界并报告可实现分值；满内圈验收等待合法且几何可行的依据，不改图骗分。

验收：覆盖 4 种颜色选 3 的 24 个排列作为算法测试；比赛 profile 按官方指定口令和初始位置运行。序列每次完成后保存每个目标位的几何判定和证据。

## P6 · 回归、耗时和演示交付

负责：张叔阳牵头，全员按模块处理失败。依赖：P5。

1. 一键启动 simulation、perception、calibration、planning、execution、task、health 和 recording；比赛口令通过参数或简洁界面输入。
2. 记录 run_id、版本、配置哈希、任务、种子、阶段耗时、失败原因、评分明细、rosbag、录像。
3. 设置官方固定场景回归与光照/噪声/轻微扰动压力测试两套 profile；压力测试不冒充官方初始布局。
4. 建议至少 100 次完整运行评估，记录成功率与失败分布；完整序列成功率目标 ≥95%，单块抓放目标 ≥99%，均需报告样本量和测试条件。
5. 流程可靠后优化观察次数、非关键段速度和路径，不跳过规则要求的稳定等待。以建议 180 s 为性能参考，同时记录仿真时间、墙钟时间、实时率。
6. 固定第三视角连续演示，显示完整机械臂、底图、电池、口令和计时；输出运行指南、技术说明、第三方及生成式 AI 使用记录。

验收：干净终端可重复启动并重现记录；所有失败能定位阶段；示例视频完整连续；README 明确复现命令、系统版本、模型来源、完成项及剩余限制。
