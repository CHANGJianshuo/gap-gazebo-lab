SJM 实现唯一的 Task Manager、抓放动作和执行层，负责选择目标、推进任务、夹爪开闭及失败后的任务恢复。常建烁提供运动规划能力，接收明确的运动目标，返回轨迹及规划失败原因；SJM 根据结果决定执行、重新规划或结束任务。

感知提供电池观测，韩明赫维护向基座的坐标转换。建议由 SJM 的抓放动作层结合夹具/TCP 几何生成末端候选目标，再调用常建烁的规划模块；常建烁验证可达性并规划无碰撞运动。IK 解通常是规划中间结果，主要对外交付为带时间的关节轨迹。

张叔阳牵头仿真工程；SJM 验证机器人及夹具模型，韩明赫复核底图尺度和坐标，孙浩然验收相机输出。按模块协作不等于各人维护独立且不兼容的世界文件。

腕部相机要求对原分工示例作具体适配：`camera_link` 应连接机械臂末端，而不是直接固定在 `robot_base`。推荐关系见 [接口约定](../architecture/INTERFACES.md)。

每个模块 README 写清输入、输出、职责和验收。共享配置和跨模块接口更改应同步到本责任表对应成员。尚未提供成员 GitHub 账号，因此未编造 `.github/CODEOWNERS`。

初赛暂不建立导航、SLAM 或移动底盘包；现有坐标、感知、操作和运行记录接口可供决赛复用。
