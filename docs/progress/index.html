五步看懂运动规划

① IK：终点怎么摆

目标是夹爪的位置和朝向，电机需要六个关节角。逆运动学把二者联系起来。同一个目标可能存在多种关节姿势。

② 避障：中间怎么走

不仅检查夹爪，还检查肘部、相机和提着的电池。找到终点姿势，不代表途中一定走得过去。

③ 优化：减少无效运动

比较不同关节解和路线，删除多余绕行。样条可以表达曲线，但“光滑”本身并不保证避碰。

④ 排时间：何时加减速

同一条路线可以快走或慢走。速度、加速度、jerk 和力矩约束决定能压缩多少运动时间。

⑤ 执行：用反馈说话

控制器跟随参考轨迹，Gazebo 计算物理响应。记录实际误差、碰撞和是否放稳，才能判断方案能否执行。

锁扣如何提起电池

张开 → 对准把手 → 闭合 → 提升 → 搬运 → 下放 → 打开 → 垂直撤离。每一步都要更新碰撞模型。

这里的“最优”是什么意思？

对多个 IK 解、直接 Ruckig 与 B 样条候选进行验证，选择其中执行时间最短的一条。避障失败时使用 RRT-Connect 后备。它不保证全局最优；质量、加速度、jerk 和锁扣结构仍需实机标定。

多项式与 B 样条属于哪一步？

它们是表达曲线的方法。用无量纲进度表达时是路径；加上时间后是轨迹。可以优化多项式系数或 B 样条控制点，也可以用分段多项式在控制器采样点之间插值。直接优化带时间的关节样条，可以同时处理路线、快慢和平滑性。

为什么压缩一点时间，电机负担会明显增加？

相同路径均匀缩短为一半时间，速度变为 2 倍、加速度 4 倍、jerk 8 倍。下面是单关节五次多项式的知识示意，不是本次实验数据。

蓝线：关节角度；绿色：归一化显示的速度。真实限值取决于机器人与负载。
